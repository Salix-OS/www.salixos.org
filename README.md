# www.salixos.org

This is the source of the [Salix](https://salixos.org) website, a static site
built with [Hugo](https://gohugo.io/). The site uses no JavaScript.

- `make serve` to preview locally
- `make upload` to build and deploy to the server
- `make publish` to build and push to the `public` branch (GitHub Pages)

Pages are in `content/`; downloads, donations, screenshots and sponsors
are listed in `data/`.
