Salix is developed by an open community of volunteers and contributors all over the world. Here is how you can reach us and get involved.

Get in touch

Forum

The Salix forum is the main place to ask questions, get support and talk with the Salix team and other users.

IRC channel

You can also reach us online using our IRC channel. It is named #salix and is hosted on the irc.libera.chat IRC server. You can use your favourite IRC client to connect, or you can connect with your web browser through the web interface that libera.chat provides.

Please be patient when asking a question. Not everyone lives in the same timezone as you do, and even if they do, they might not be available at that particular time. You might get an answer instantly, or you might have to wait a few hours until someone is able to reply.

Mailing list

The salix-main mailing list is the main discussion and development mailing list for Salix.

All developers are requested to subscribe, as most of the development is discussed there. Translators should also subscribe, as notifications about new strings that need to be translated in the software developed in-house are regularly posted there. All users are welcome to subscribe too and share their ideas and opinions about everything concerning the project.

You can subscribe, unsubscribe and view the list archives using the salix-main info page.

The mailing list address is salix-main@lists.sourceforge.net. Messages from unsubscribed users are moderated, so it may take some time until your email actually reaches the list, and with a large enough moderation queue, it may be missed entirely. Messages from subscribers always reach the list instantly, so if you want to send an email to the mailing list, subscribing is a good idea.

Mastodon

Follow @salix@fosstodon.org for news and announcements.

Get involved

Translate

A lot of the software used in Salix is developed in-house. Users from around the world can help us by translating it into their own language.

The Salix translation project is hosted by Transifex. Most of the resources available for translation can be found on the Salix project page at Transifex.

There are also additional resources that are not included in the main Salix project page but are available for translation as well, mainly because some of them are large enough to warrant their own project pages, and some were created as separate projects before the main Salix project page existed.

Here is everything you can translate at Transifex:

  • Salix project: several tools used in Salix, including the installer.
  • Salixtools: the Salix system tools (console version).
  • SalixtoolsGTK: the Salix system tools (GTK version).
  • Slapt-get: the package management tools that Salix uses.
  • Dotnew: a utility to process .new configuration files.
  • Flatpak-tools: tools to manage flatpak and flatpak-related files.

Report bugs and submit packages

  • Bugtracker: report bugs and problems you find in Salix.
  • Package submissions: submit new packages for the Salix repositories.
  • SourceForge project page: the Salix project at SourceForge, including older releases.
